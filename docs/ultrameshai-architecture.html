Config-Driven Model Routing

Model tier aliases and loop mappings are loaded from crates/cognition/config/models.toml at compile time. Git-tracked, CI-validatable, zero opencode restart required.

crates/cognition/config/models.toml 
# Model tier aliases
[tiers]
FRONTIER = "meta-llama@latest?params>=70"
REASONING = "deepseek@latest"
CODE_BEST = "code_chat@latest"
CODE_MID = "code_chat@latest?params>=14"
CODE_SMALL = "mistral@latest"

# Loop → tier mappings (48 total)
[loops]
deepwork = "FRONTIER"
bruteforce-coder = "CODE_BEST"
fix-implementer = "CODE_BEST"
juniors = "CODE_SMALL"
